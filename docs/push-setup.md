# Пуш-уведомления: настройка (один раз)

Приложение уже умеет всё на своей стороне. Осталось подготовить Supabase: создать таблицы, загрузить функцию, которая рассылает напоминания, и включить расписание.
Все секретные значения лежат в локальных файлах `supabase/push-secrets.local` и `supabase/cron-send-reminders.sql.local`. Они **не попадают в git**, откройте их в Cursor. Никому их не отправляйте.

## Шаг 1. Таблицы (SQL)
1. Supabase → **SQL Editor → New query**.
2. Вставьте всё содержимое файла `supabase/migrations/006_push.sql`, нажмите **Run**. Должно быть «Success».

## Шаг 2. Функция рассылки
1. Supabase → **Edge Functions → Deploy a new function** (кнопка **Via Editor**, если есть выбор).
2. Имя функции: **`send-reminders`** (ровно так).
3. Удалите весь пример кода в редакторе и вставьте содержимое файла `supabase/functions/send-reminders/index.ts`. Нажмите **Deploy**.
4. Откройте настройки этой функции (**Details / Settings**) и **выключите проверку JWT** («Verify JWT» / «Enforce JWT Verification» → Off). Сохраните. Функцию защищает собственный секрет, а не JWT.

## Шаг 3. Секреты функции
1. Supabase → **Edge Functions → Secrets** (или **Manage secrets**).
2. Откройте в Cursor файл `supabase/push-secrets.local`. В нём 4 строки вида `ИМЯ=значение`.
3. Добавьте **каждую** как отдельный секрет: имя слева от `=`, значение справа (без пробелов и кавычек):
   `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`, `CRON_SECRET`.
4. Сохраните.

## Шаг 4. Расписание (раз в минуту)
1. Откройте в Cursor файл `supabase/cron-send-reminders.sql.local` и скопируйте всё его содержимое.
2. Supabase → **SQL Editor → New query**, вставьте, нажмите **Run**.
3. Если пишет, что расширение не найдено: **Database → Extensions**, включите `pg_cron` и `pg_net`, затем повторите запуск.

## Шаг 5. Выложить приложение
Сделайте commit и push (или попросите меня «задеплой»). Через 1–2 минуты обновите сайт (Ctrl+Shift+R).

## Шаг 6. Включить на устройстве
**Компьютер или Android (Chrome):**
открыть сайт → слева внизу на email → **Уведомления** → **Включить на этом устройстве** → в окне браузера нажать «Разрешить».

**iPhone** (обязательно именно так, иначе iOS не присылает уведомления сайтам):
1. Откройте сайт в **Safari**.
2. «Поделиться» (квадрат со стрелкой) → **На экран «Домой»** → Добавить.
3. Откройте **Planner с иконки на экране** (не из Safari).
4. Нажмите на кружок с буквой вверху справа → **Уведомления** → **Включить** → Разрешить.

В окне уведомлений отметьте, **когда напоминать**: за день, за час, за 15 минут, в момент дедлайна.

## Шаг 7. Проверка
1. В окне уведомлений нажмите **«Проверить»**: должно прийти тестовое уведомление (проверяет, что устройство вообще их показывает).
2. Настоящая проверка: отметьте «В момент дедлайна», создайте задачу с дедлайном через 3–4 минуты и подождите. Уведомление придёт в течение минуты после дедлайна.

## Если не приходит
- В Supabase → Edge Functions → `send-reminders` → **Logs**: есть ли записи раз в минуту? Если ошибка `forbidden`, значение `CRON_SECRET` в секретах и в SQL расписания не совпадает (в файлах `.local` оно одно и то же).
- Проверить, что расписание работает (SQL Editor):
  `select status, return_message, start_time from cron.job_run_details order by start_time desc limit 5;`
- Устройство не включено в приложении (шаг 6) или на iPhone открыто не с иконки.
- Дедлайн у задачи не указан или задача уже выполнена: напоминания идут только по открытым задачам с дедлайном.
- Напоминание отправляется один раз для каждого срока (журнал `reminders_sent`). Если вы изменили дедлайн, оно сработает заново.
