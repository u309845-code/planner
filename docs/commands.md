# Шпаргалка по командам

Все команды вводятся в **PowerShell** (клавиша Windows → `PowerShell` → Enter). Вставка — правая кнопка мыши или Ctrl+V.

## Тестовая версия на своём компьютере
```
cd C:\Users\Julien\Desktop\Julien_planner-bot\web
npm.cmd run dev -- --host 127.0.0.1
```
Откройте http://127.0.0.1:5173. Остановить — **Ctrl+C**. Страница обновляется сама при сохранении файла.
Тестовая версия работает с той же базой, что и сайт: данные общие.

## Проверить, что код собирается
```
cd C:\Users\Julien\Desktop\Julien_planner-bot\web
npm.cmd run build
npm.cmd run lint
```

## Сохранить изменения (git)
```
cd C:\Users\Julien\Desktop\Julien_planner-bot

git commit -m "Что я изменила"
```
`git status` показывает, какие файлы изменены. Коммит сохраняет изменения только на компьютере.

## Выложить на сайт
```

```
Через 1–2 минуты сайт обновится (вкладка **Actions** на GitHub покажет ход сборки).

## Правлю сама в Cursor и выкладываю на сайт

1. **Откройте файл** слева (код в `web/src`), измените текст и нажмите **Ctrl+S**.
2. **Посмотрите результат** в тестовой версии (она обновляется сама). Если сервер не запущен: Terminal → New Terminal, затем
   `cd web` и `npm.cmd run dev -- --host 127.0.0.1`, адрес http://127.0.0.1:5173
3. **Проверьте, что сборка проходит.** В терминале Cursor, в папке `web`: `npm.cmd run build`.
   Если в конце написано `built in ...`, всё хорошо. Если красные ошибки с номером строки, вы что-то сломали: исправьте или отмените (см. ниже).
4. **Сохраните в git:** слева значок с ветвью (Source Control, Ctrl+Shift+G) → введите короткое описание, например `Поправила название` → кнопка **Commit**.
   Если спросит про «Stage all changes», ответьте Yes.
5. **Выложите на сайт:** кнопка **Sync Changes** (или три точки → Push). Через 1–2 минуты сайт обновится
   (GitHub → вкладка Actions покажет ход сборки, нужны зелёные галочки). Обновите сайт через Ctrl+F5.

### Если что-то сломалось
- **Отменить правки в одном файле, пока не сохранили в git:** Source Control → наведите на файл → значок стрелки назад (Discard Changes).
- **Уже выложили, а сайт сломался:** напишите мне, я откачу последнюю версию.
- **Ошибки сборки не понятны:** скопируйте текст ошибки и пришлите мне.

### Что можно править смело
- Тексты на экране (надписи, подсказки): ищите нужное слово через Ctrl+Shift+F (поиск по всем файлам).
- Названия и цвета тегов: `web/src/tags.ts`
- Название вкладки браузера: `web/index.html` (строка `<title>`)
- Размеры, отступы и цвета в `className` (например, `text-sm`, `bg-white`): подсказки по классам на tailwindcss.com

### Осторожно
- `web/src/store.ts`, `stats.ts`, `recurrence.ts` — логика, где легко сломать подсчёты. Правьте с предупреждением мне.
- `supabase/migrations` — это файлы для базы, выполняются только вручную в Supabase, в git они только хранятся.
- Файл `web/.env.local` с ключами не открывайте и никому не отправляйте.
- Если мы оба правим код, сохраните и сделайте коммит до того, как попросите меня что-то менять, или предупредите.

## Открыть проект в Cursor
Cursor → File → Open Folder → `C:\Users\Julien\Desktop\Julien_planner-bot`
Или из PowerShell, находясь в папке проекта: `cursor .`

## Если что-то не так
- «Выполнение сценариев отключено» — пишите `npm.cmd`, а не `npm`.
- Страница не открывается — проверьте, что окно PowerShell с сервером не закрыто, и откройте адрес `http://127.0.0.1:5173` (не `localhost`).
- Не обновилась база — в Supabase выполните новые файлы из папки `supabase\migrations` по порядку.
