# Каким будет проект

Личный планер менеджера по продажам: **одно место для задач, мыслей, встреч и всего, что с ними связано.**

## Принципы (важнее любых функций)
1. **Быстро.** Добавить задачу или мысль — за несколько секунд. Прошлые планеры и Notion бросались из-за сложности.
2. **Дедлайны на виду.** Отдельные подборки: «горит» (до дедлайна ≤ 1 дня) и «скоро» (≤ 3 дней).
3. **Видимый результат.** Выполненное должно быть заметно (прогресс дня/недели). Задачи — небольшие и законченные.
4. **Не перегружать.** Если функция усложняет ежедневное использование — не делаем.
5. **Приятный интерфейс**, удобный на телефоне и компьютере.

## Что хранится
Всё — один тип записи с разными видами:
- **Задача** (срок, приоритет, план времени, факт времени)
- **Встреча** (время, клиент)
- **Заметка / мысль** (быстрый захват во «Входящие», потом разбор)

У записи: теги (встреча, клиент, внутренняя встреча, личное, проект…), цвет категории, приоритет, дедлайн, плановое и фактическое время.

## Виды
- **Фокус дня** — несколько главных задач на сегодня
- **Дедлайны** — «до 1 дня» и «до 3 дней»
- **Неделя** по дням, **месяц**; перетаскивание задач между днями
- **Входящие** — сюда падает всё быстро записанное
- Фильтр по тегам

## Время
- План на задачу и **таймер**, который запускает сама пользователь
- Статистика: сколько уходит на теги/виды задач; план против факта (калибровка оценок)

## Статистика выполненного
Сколько задач закрыто за неделю, месяц и дальше; по тегам; сравнение с прошлым периодом. Показывать достижения, а не упрёки.

## Трекер привычек (мотивирующий, не давящий)
- Без «красных» пропусков и штрафов: серия не «сгорает», а мягко продолжается («5 из 7 дней на этой неделе»)
- Акцент на прогрессе и маленьких победах, поддерживающие формулировки
- Цель недели вместо идеальной ежедневной серии; возможность поставить привычку на паузу
- Отдельный лёгкий раздел, не смешанный со списком задач

## Ритуал недели
Каждый понедельник — список задач недели → раскладка по дням с приоритетом и оценкой времени → факт времени записывается по ходу недели. Цель: всё в срок или раньше.

## ИИ (после накопления данных)
1. Раскладка недели из списка задач (по понедельникам)
2. Разбор текста в задачу («созвон с клиентом завтра в 15:00»)
3. Анализ: куда уходит время, где оценки слишком оптимистичны
4. Предложения по календарю

## Заметки о стиле работы (гипотезы, не факты)
Тяжело долго сидеть на месте, нужна разная работа с законченным результатом, не нравится неструктурированная среда. Значит: короткие блоки времени, мелкие законченные задачи, понятная структура недели.

## Позже / по требованию
- Синхронизация с календарём iPhone (только если понадобится)
- Работа без интернета

## Осторожно
Приложение публичное в интернете (вход только по паролю). Не хранить в нём персональные и конфиденциальные данные клиентов — только то, что не навредит, если утечёт (имя компании и суть задачи, без телефонов, договоров и цен).
