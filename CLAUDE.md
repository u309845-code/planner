# Planner bot

Личный Telegram-бот-планер на русском языке. Один владелец (OWNER_ID), остальные игнорируются.

## Стек
Node.js 24 + TypeScript, grammY (long polling), встроенный `node:sqlite`, chrono-node (`chrono.ru`) для разбора дат, luxon для часовых поясов.

## Команды
- `npm run dev` — запуск с автоперезапуском
- `npm run typecheck` — проверка типов

## Структура
- `src/bot.ts` — команды, кнопки, цикл напоминаний (раз в 10 с)
- `src/db.ts` — SQLite (`planner.db`), задачи и настройки
- `src/parse.ts` — разбор «текст + когда» и форматирование времени

## Правила
- Токен только в `.env`, никогда в коде, логах и git.
- Время хранится в unix ms (UTC), показывается в часовом поясе из настройки `tz`.
- Тексты бота на русском.
